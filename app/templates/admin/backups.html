Warehouse Reliability & Disaster Recovery
  • Online Non-Blocking: Database snapshots capture transactions without halting or corrupting in-flight scans.
  • Automatic Safety Copy: If you restore an old backup, the system automatically saves a safety copy of the current database before replacing it.
  • Integrity Checked: Restores are verified using SQLite PRAGMA integrity_check before being applied.
  • Windows Task Scheduler: Configure Windows Task Scheduler to run daily copies of the backups/ folder to an external network share or drive.
